Rough Stroke

Redraws the strokes of a vector drawing as rough, hand-drawn strokes. Add Rough Stroke from the Stylize category and connect a vector level to Source, directly or through transforms. The result is the rough strokes alone; fills are not drawn. Any other kind of source passes through unchanged.

Stroke

Drawn Width Scale multiplies the width the stroke was drawn with, and Added Width adds to it: scale 0 with an added width gives every stroke the same width. Swell In and Swell Out are the shares of a stroke over which it grows from nothing and shrinks back, like pen pressure.

Copies

Copies draws each stroke that many times. The first copy follows the stroke; the others sit beside it, up to Copy Offset away, for a sketched look. The randomness amounts thin and fade copies at random.

Colour

Stroke Colour uses each stroke's own style colour. Gradient runs from Start Colour to End Colour along each stroke. Over Source draws the rough strokes on top of the source drawing, which keeps its fills.

Wave and drift

Wave Amplitude bends each stroke from side to side once every Wave Length; Wave Phase slides the bends along, and Wave Phase Randomness gives each copy its own phase. Drift lets a copy wander slowly off the stroke, in features as long as Drift Size.

Reveal

Reveal Start and Reveal End pick the stretch of each stroke that is drawn, as shares of its length; animate Reveal End from 0 to 1 to draw the strokes on. Travel moves that stretch along the stroke, and Speed moves it by that share every frame without keys. With Loop a stretch that leaves one end comes back at the other.

Timing

Hold redraws the copies, drift and randomness every that many frames, which makes the strokes boil; 0 never redraws. Seed picks the arrangement, so renders are repeatable.

Starting points

Sketch: Copies 3, Copy Offset 3, Drift 1, Hold 2. Draw on: animate Reveal End from 0 to 1. Marching dashes: Reveal End 0.2, Loop on, Speed 0.02. Brush: Drawn Width Scale 3, Swell In and Swell Out 0.4.

Notes

Every value except Loop and Over Source can be animated. 8-bit, 16-bit and floating-point renders are supported. The strokes are read from the drawing itself, so effects that deform the drawing before Rough Stroke are not seen by it.
