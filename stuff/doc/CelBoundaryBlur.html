Cel Boundary Blur

Soften boundaries between covered cel colors while retaining the original silhouette. Add this effect from Blur and connect Source. Use Cel Color Keep or Cel Color Key upstream to isolate the colors to blend.

Controls

  • Blur Amount: filter radius, from 1 to 100 source pixels; default 10.
  • Blur Smoothness: percentage mixed with the filtered colors, from 1 to 100; default 50. Larger amounts and smoothness give wider, stronger transitions.
  • Number of Repeat: from 0 to 10; default 1. Each repetition filters both axes. Zero passes the source through unchanged. Animated values round to the nearest whole number, with halves rounded upward.
  • Bias Direction: Vertical, the default, finishes each repeat with a vertical pass. Horizontal finishes with a horizontal pass. Irregular alpha masks make these results differ. Choice keys use stepped interpolation.

Colors and transparency

Each axis uses a triangular filter. Samples are weighted by their coverage, then normalized by the total coverage. Fully transparent samples contribute nothing; each destination retains its original alpha. Partial transparency does not darken edges. Colors can blend across transparent gaps within the amount, but those gaps stay transparent. Float processing preserves finite HDR colors.

This is a native cel filtering adaptation. Its explicit triangular kernel, pass ordering and defaults define this effect; they do not claim binary output equivalence with another application's effect.

Animation and rendering

All four controls support native keys, undo, presets, scene saving and macro exposure. Amount follows the rendering scale. Rotation, reflection and shear are applied by the host after filtering in the cel's axes. Both axes request the complete radius times repeat count, so strips match a whole-frame render. The alpha bounds never expand. Cancellation clears the unfinished tile.

The working image is limited to approximately 13 million pixels including the filter margin. Larger requests report an allocation limit instead of silently reducing quality. Use smaller render tiles for large images.
