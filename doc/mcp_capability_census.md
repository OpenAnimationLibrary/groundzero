# MCP capability census

Generated by `ci-scripts/mcp_census.py --update` from `ci-scripts/mcp_census.json`.
Edit the data file, never this document. CI fails when this document is stale.

An outcome is something an artist wants done. A tool is one typed operation. One outcome
can need several tools, and one tool can serve several outcomes.

## Measures

These three counts are separate. A fully classified inventory does not mean every
outcome is automated, and a tool with a listed test is not a platform qualification.

## File formats

A supported format names the catalog entry that shows it. A refused format is one the
README mentions only to say that it is rejected.

| Format | Role | State | Catalog evidence or reason |
|---|---|---|---|
| png | level and drawing import, drawing export, preview and sequence output | supported | `raster.import_png` describes PNG |
| mp4 | opaque movie output | supported | `render.submit` accepts format `mp4` |
| pli | storage of vector levels in saved packages | supported | `level.create` accepts format `vector` |
| tnz | scene file in saved packages | supported | `scene.save_copy` is in the catalog |
| wav | sound import and mixdown output | supported | `audio.import` describes WAV |
| aiff | sound import | supported | `audio.import` describes AIFF |
| aifc | sound import | refused | audio.import returns unsupported_format |
| papagayo_dat | lip-sync timing import | supported | `lipsync.import` accepts format `papagayo_dat` |
| rhubarb_tsv | lip-sync timing import | supported | `lipsync.import` accepts format `rhubarb_tsv` |
| rhubarb_json | lip-sync timing import | supported | `lipsync.import` accepts format `rhubarb_json` |
| tpl | studio palette files read from a granted root | supported | `studio_palette.list` describes .tpl |
| psd | level files in a read-only user scene | refused | scene.open_read_only reports a level in this format as not_applicable and does not load it |
| exr | level files in a read-only user scene | refused | scene.open_read_only reports a level in this format as not_applicable and does not load it |
| svg | level files in a read-only user scene | refused | scene.open_read_only reports a level in this format as not_applicable and does not load it |
