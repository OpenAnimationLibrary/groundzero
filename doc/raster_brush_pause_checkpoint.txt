IMPLEMENTED PROGRESS, NOT A VERIFICATION CLAIM
The published implementation provides an opt-in regular RGBA8 raster brush
workflow while preserving the existing MyPaint/TLV/vector paths. It includes
native dynamics/wet painting, bounded isolated import, editable portable
presets, resource-rights-aware export and hash repair, and application
undo/cancel/frame/save integration. Versioned experimental source profiles
cover measured Pixel geometry/pressure/HSV, fixed bitmap and PNG-mask sampling,
incremental GIH, pressure Mirror, wet geometry/HSV interactions, and an explicit
timer-event airbrush runtime. Native-copy conversion discloses source-only
changes. Source import admission and reference verification are separate.

Preserved unpublished work includes source Distance state and periodic editor
support, additional masked-primary composition, fixture completeness checks,
explicit rejection of outside-contract spacing, and the failure corrections
below. The separate application-test commit covers wet HSV/texture editing,
painting, undo/redo, cancellation, persistence, export and resource repair.
These changes have not been qualified together in CI.

KNOWN FAILURES AND DIAGNOSES AT PAUSE
Parser run 41156677049 failed on Windows Qt5/Qt6 and macOS Qt6:
- Periodic Time equivalence: absolute timestamp interpolation introduced
  epoch-dependent rounding. Local fix 44022b4c8 normalizes timestamps before
  interpolation and preserves exact equivalence checks.
- Wet reverse footprint: the new test used zero pickup, preventing the legacy
  model from exposing its painted footprint. Local fix 698342c4f uses nonzero
  pickup while retaining exact footprint and partition assertions.
- Wet joint HSV: the test expected cyan for a 90-degree hue change. Local fix
  698342c4f corrects the expected encoded foreground; no tolerance is relaxed.
- Periodic HSV rejection: structurally decoded metadata was incorrectly treated
  as semantic acceptance. Local fix 7f3ebe25c checks semantic rejection, error,
  failed re-encoding and zero imported records. Production rejection remains.
- Optional airbrush field: the test edited the outer portable envelope instead
  of package.settings. Local fix 44022b4c8 corrects the test nesting.

The local fixes are committed but unpublished and untested together. Worker
process/response-file checks and native metrics passed within those failed
parser jobs; that does not make the parser suite or PR green. Stale GIH/wet-HSV
matrix-count guards were also corrected locally, with an early generated-
